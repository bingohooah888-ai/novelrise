# CHAT HANDOFF PREFLIGHT

**NOVELIGHT 新チャット切替・引き継ぎ送信前チェック**

本書は `docs/NOVELIGHT-MASTER.md` の「チャット切替・引き継ぎ」「チャット継続判定ゲート」を実行時に落とさないための補助Preflightである。

## 1. 発火条件

以下のいずれかに当てはまる場合、このPreflightを必ず通す。

- 新しいチャットへの切替を推奨する
- 「この区切りでチャットを変えた方がよい」と判断する
- 主要工程完了後のチャット継続判定で「切替」が有利と判断する
- ユーザーに次チャットで続きを行うよう案内する

## 2. 送信ゲート

**新チャットへの切替推奨は、同じ応答内にコピペ可能な引き継ぎ指示文が完成して初めて完了とする。**

以下は禁止する。

- 「新しいチャットを推奨します」だけで応答を終了する
- 「必要なら引き継ぎ文を作ります」と後回しにする
- ユーザーから「指示文は？」と聞かれるまで待つ
- 「前の内容を引き継いで」等の曖昧な一文だけで済ませる
- ユーザー自身に過去経緯の要約・書き直しを求める

上記の状態では、チャット切替案内は**未完了**として扱い、送信しない。

## 3. 同一応答に必須の3要素

切替を推奨する応答では、原則として次の3要素を同じ応答に含める。

1. **現在工程の完了状態**
   - 何が完了したか
   - 未完了・外部待ち・注意点が残っていないか
2. **チャット切替判断**
   - なぜ今切り替えるのが有利か
3. **そのまま貼れる引き継ぎ指示文**
   - ユーザーが編集・補足しなくても次チャットを開始できる形

## 4. 引き継ぎ指示文の必須内容

引き継ぎ指示文には、該当する範囲で以下を含める。

- 現在の作業目的
- 直前までに完了した重要事項
- 次に行うべき具体的な作業
- 関係するPR番号、ブランチ、Workflow Run、commit SHA、画面操作等の現在地
- 未完了事項、既知の問題、再試行中の事項があればその状態
- 開発作業では、作業開始時にGitHubの**最新main**を再取得する指示
- `docs/NOVELIGHT-MASTER.md` をmain上から再読込し、唯一の正式基準とする指示
- 分野別の正式ガイドやPreflightがある場合、それらも最新mainから再読込する指示
- 過去のSHAを記載する場合でも、それを最新値として固定せず「確認時点の値」と明示する
- NOVELIGHT実作業では、最初のツール実行前に全体と主要工程の予想所要時間を提示する指示
- 次工程で絶対に守るべき禁止事項・品質条件がある場合、その要点

## 5. 引き継ぎ文の品質条件

- 冒頭だけで「何の続きか」が分かる
- 次チャット側が前チャットの会話ログを持っていなくても開始できる
- 過去の会話要約や記憶を正式な状態とせず、GitHub・MASTER・正式資料を再確認させる
- 最新状態が変わり得る情報は、次チャット開始時に再確認するよう明示する
- 次に何をすればよいかが1つ以上、具体的に書かれている
- ユーザーに経緯の再説明を要求しない
- 長さを理由に必要事項を省略しない。ただし不要な会話経緯は削る

## 6. 送信直前セルフチェック

新チャット切替を推奨する前に、以下を全て確認する。

- [ ] 現在工程が安全に区切れている
- [ ] 切替推奨の理由を説明した
- [ ] **同じ応答内にコピペ可能な引き継ぎ指示文がある**
- [ ] 引き継ぎ文に現在の目的・完了事項・次作業がある
- [ ] 必要なPR・branch・Workflow・commit等の現在地がある
- [ ] 次チャットで最新mainと最新MASTERを再取得する指示がある
- [ ] 必要な分野別正式ガイドの再読込指示がある
- [ ] 作業開始ゲート（所要時間提示）の指示がある
- [ ] 古いSHAや過去要約を正式基準として固定していない
- [ ] ユーザーに不足情報の書き直しをさせる状態になっていない

**1つでも未確認なら、切替推奨の応答を送信しない。**

## 7. 固定テンプレート

必要に応じて、以下の骨格を使う。

> NOVELIGHTの【作業テーマ】の続きです。
>
> まずGitHubの最新mainと、main上の `docs/NOVELIGHT-MASTER.md`、および今回必要な正式ガイド／Preflightを取得・再読込し、それらを正式基準として確認してください。
>
> 直前までに【完了事項】まで完了しています。確認時点のmainは【SHA】ですが、作業開始時に必ず最新mainを再取得してください。
>
> 現在の重要な状態は【PR／Workflow／branch／未完了事項】です。
>
> 次の作業は【具体的な次工程】です。
>
> 【今回特有の禁止事項・品質条件】を守って進めてください。
>
> NOVELIGHTの作業開始ゲートに従い、最初のツール実行・生成・編集・GitHub操作より前に、全体と主要工程ごとの予想所要時間を提示してください。

---

このPreflightはMASTERの既存ルールを置き換えるものではない。MASTERが上位基準であり、本書は「ルールを知っていたのに出力時に落とす」失敗を防ぐための実行用チェックとして扱う。
