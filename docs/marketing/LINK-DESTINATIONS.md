# NOVELIGHT 新規告知リンク運用（2026-10-24 決定）

## 新しく発行するリンクの既定

- これから制作する **X投稿、作者へのDM、広告バナー／キャンペーン紹介、その他の一般向け告知** では、NOVELIGHT全体を案内するリンク先を **https://novelight.jp/** に統一する。
- 特定の行動を直接案内する場合（星灯祭への応募、交流広場の閲覧、作品を読む等）は、ホームを経由せず、該当する正式な機能ページへ直接リンクしてよい。
- **新しい告知に `https://novelight.jp/welcome.html` や `/welcome` を使用しない。** 読者が到達するまでの中継画面・余計なクリックを増やさない。
- 投稿案やDM文面を作成するときも上記を既定とし、リンク先は目的に応じて選ぶ。

## 既存のX投稿・DMを保護

- すでに投稿済みのXや送信済みのDMのリンク先・プレビューは変更しない。
- **`welcome.html` は維持**し、既存訪問者が引き続きページを開けるようにする。削除、404化、ホームへの強制リダイレクトは行わない。
- 既存のXカード用PNG（`/assets/ogp/novelight-card-20261022.png`）、トップのOG/Twitterカード設定、および `welcome.html` 自身のOG/Twitterメタ情報を変更しない。

## 適用範囲

この運用ルールは**今後の新規リンク**に適用する。すでに外部のX/広告マネージャー/DMに保存されたリンク先をサイトのコードから変更できるという意味ではない。新しい広告を出稿する場合は、出稿時の遷移先URLを上記へ設定する。
