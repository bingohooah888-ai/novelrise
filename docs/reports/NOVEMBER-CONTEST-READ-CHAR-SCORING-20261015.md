# 第1回 星灯祭 — 有効読了・本文文字数・ポイント判定仕様（2026-10-15）

## 1. 有効読了の根拠

1. 通常の読書と共通の有効読書判定（`public.valid_read_rules` id=1）に沿った、サーバーが観測する読書進捗・経過時間の資格判定を満たす。
2. 通常読書のルールと同じく、800文字未満などの短編に対する基準は、`normal_min_chars`・`short_progress_ratio`・`normal_foreground_seconds`・`min_short_foreground_seconds` から算出する。任意のJS自己申告や固定の30/45秒のみで認定しない。スクロール／読み上げとも同じ共通基準に従う。
3. さらにコンテスト固有の**最低本文200文字以上**、開催期間、公開・区分、応募資格、自作除外、読者・ゲスト識別、不正審査を満たすこと。通常読書では有効な200文字未満の話であっても、コンテスト得点には含めない。
4. コンテストの読了証跡はservice_roleのみで追加し、ゲストを含めprivate読者識別子で管理する。同一読者・同一作品・同一エピソードは一回のみ。ブラウザから送られる文字数・ポイントは採用しない。

## 2. 同一読者・同一作品の得点判定

| 異なる有効読了話数 | 対象話の合計本文文字数 | 合計得点 |
| --- | ---: | ---: |
| 3話以上 | 1,500文字以上 | 1pt |
| 5話以上 | 3,000文字以上 | 3pt |
| 10話以上 | 6,000文字以上 | 5pt |

**各段階で話数と文字数の双方が成立すること**。複数段階を加算せず、成立した最高段階のポイントで置換。例：10話・4,000文字→3pt、5話・1,400文字→0pt、2話・10,000文字→0pt。各読者・作品の最大は5pt。

- 本文文字数は、サーバー側の公開エピソード`episodes.content`を`char_length(coalesce(content,''))`で計測し、認定イベントにスナップショットする。NOVELIGHTの通常有効読書で使用する本文文字数算定と一致させる。
- 本文200文字未満の話は有効読了話数・合計文字数の両方から除外。200文字ちょうどなら最低文字数を満たすが、話数と合計文字数を満たすまで得点は0pt。
- 同じ話の再読やゲスト→ログインの統合では1回だけ計算し、本文文字数も二重に足さない。公開後に本文が編集されても、確定済み読了の文字数スナップショットを事後に勝手に変更しない。
- review_hold、excluded、mergedの得点は従来どおり無効。審査結果で残る証拠を再計算し、過去の累積得点を足し込む方式は使用しない。
- 中間ランキングは固定時刻までの読了イベント証拠から同じ3つの閾値で再集計する。読者別現在得点とランキングを別基準にしない。

## 3. 不正対応と異議

文字数の不自然な水増し・無意味な文章の大量投稿・自動操作・なりすまし等、ポイント獲得を目的とした不正は運営審査の対象。合理的な審査で不正が確認された場合は該当ポイントの無効化や参加資格取消を行い得る。独立した審査・監査記録・異議申立て（期限なし）を維持し、自動的な恣意的失格や根拠なき賞金減額は行わない。

## 5. 境界値の検証

- 3話1,499字→0pt／3話1,500字→1pt
- 5話2,999字→1pt／5話3,000字→3pt
- 10話5,999字→3pt／10話6,000字→5pt
- 199字の話がサーバーでqualifiedになってもコンテスト得点イベントは追加しない
- 同一話再送は得点・文字数を二重に増やさない
- guest→accountの証拠統合で文字数スナップショットを引き継ぐ
- 暫定ランキングは読者単位と同一の二軸判定を使い、複数段階の加算をしない

**注記**：短い作品の実際の有効読書判定は通常サイトと共通ですが、コンテスト得点認定には最低200文字という追加条件があります。表現上、この2段階の区別を維持してください。
