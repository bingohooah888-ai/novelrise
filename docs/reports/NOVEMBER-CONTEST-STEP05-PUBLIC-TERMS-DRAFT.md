# 【非公開草案・公開禁止】NOVELIGHT 第1回小説コンテスト 応募要項（v0.9）

> 2026-10-12 作成／工程⑤。これは**公開・承認前の作業草案**であり、利用者への正式な約束ではない。未確定項目が1件でも残る間は本書を配信・公開しない。正式な中核ルールの正本は Issue #2120。既存のNOVELIGHT「利用規約」「投稿ガイドライン」「プライバシーポリシー」に従い、その内容を黙って変更しない。

## 1. 主催・趣旨
NOVELIGHTによる第1回小説コンテスト。埋もれた物語にも読まれる機会を設け、作品を読み進めた読者の有効読書数に基づいて作品を評価する企画です。

## 2. 参加費と応募方法
- **応募・読書とも無料**。有料会員契約や購入は応募条件にしません。
- NOVELIGHTへログインした作者が、自身の**公開済み10話以上の作品**から**1作品だけ**応募できます。既に公開していた作品も応募できます。
- 応募入口はコンテスト特設ページと「自分の作品」ページの2か所です。
- 応募締切は**2026年10月31日（土）23:59:59（日本時間）**。サーバーの締切判定に従います。
- 締切までの応募作品変更・取消は可能です。締切後は不可。
- 応募は投稿作品の著作権をNOVELIGHTへ譲渡するものではありません。既存利用規約の非独占的な掲載・告知許諾は引き続き適用されます。

## 3. コンテスト期間
2026年11月1日（日）00:00から11月30日（月）23:59:59まで（日本時間）。12月1日00:00以降は新規のコンテスト読書得点を計上しません。

## 4. 読書ポイントの仕組み
コンテスト期間中、**1人の読者が1作品で有効に読んだ異なるエピソード数**に応じ、その読者がその作品へ与える得点は次の**最高到達段階だけ**になります。

| 異なる有効読書話数 | 読者1人・作品1つの得点 |
|---|---:|
| 0〜2話 | 0pt |
| 3〜4話 | 1pt |
| 5〜9話 | 合計3pt |
| 10話以上 | 合計5pt（上限） |

途中段階のポイントを足し算しません。同じ話を何度読んでも、その話の有効読書は重複計上しません。ログインしていない読者も対象です。作者による自作品の読書は得点対象外です。

**注：** 有効読書の具体的な判定方法・不正検知・同一読者判定は、後続工程⑥⑦で実装・安全性検証後に公開仕様へ反映します。一般PV、SCOUT XP、LIGHT SEED、通常ランキングとは別の記録です。現在の本番環境では読書ポイント計測は未開始です。

## 5. 順位・中間発表
中間順位は11月7日、15日、22日のそれぞれ**12:00（日本時間）**に更新します。最後の中間表示は11月30日まで維持し、最終結果は11月30日終了後の不正審査・集計確認を経て発表します。中間順位と最終順位は異なる可能性があります。

## 6. 賞金
順位**1〜5位以内の作品に、それぞれ10,000円**を授与します。入賞境界で同点の作品は**同順位としてすべて受賞**し、受賞作品数と総額は5作品／5万円を超える場合があります。運営からの銀行振込を予定します。**0pt作品の受賞資格・賞金の受取対象地域・期限・税務・必要な本人確認情報は未確定です。これらが確定するまで正式告知できません。**

## 7. 参加資格・作品区分（要決裁）
参加可能な年齢、未成年の法定代理人同意と賞金受領方法、R15・R18作品の参加範囲、AI生成主体作品の参加範囲は**現在未決定**です。既存の投稿ガイドラインが定めるR15警告・読者設定、R18専用ゾーン、AIゾーンを変更する趣旨ではありません。**審査前の草案を根拠に参加資格を推定しないでください。**

## 8. 公正性・受賞判定（要補足）
BOT、複数アカウント・端末を用いた意図的な水増し、作品関係者による組織的な不正読書、金品との交換による読書誘導など、コンテストの公正性を損なう行為を禁止します。不正が疑われる読書記録は検証対象になります。
