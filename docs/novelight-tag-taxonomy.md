# NOVELIGHT Official Tag Taxonomy

**正式基準日：2026年9月20日**

この文書は `docs/NOVELIGHT-MASTER.md` 第48章から参照される、作品公式タグのcanonical taxonomyである。表示名は変更可能だが、内部IDは一度公開した後に再利用・意味変更しない。

## 運用原則

- メインジャンルは作品ごとに1つ。百合／GL、BL、TS／性別転換等はメインジャンルを増殖させず横断公式タグとして扱う。
- 1作品の公式タグ上限は10個。作者自由タグは別枠で最大5個。
- 同義語・表記揺れはaliasへ集約する。同じ概念の公式タグを別IDで増やさない。
- 同じ表示候補が複数カテゴリに現れた場合、canonical tagは1件だけ保持し、最初に定義された主カテゴリへ所属させる。
- 公式タグは作品Rank、LIGHT SEED、課金露出その他の作品評価値へ直接加点しない。
- AIによる自動タグ付与はβ公開後の別workstream。β版では作者選択と決定論的検索だけを扱う。

初期canonical tag数：296件。
