# NOCTER PREFLIGHT

**ノクター公式素材 制作開始前チェック**

ノクターの画像生成・編集を開始する前に、毎回このチェックを通す。

## A. 作業開始ゲート

- [ ] NOVELIGHTの実作業として、全体と主要工程ごとの予想所要時間を先に提示した
- [ ] 10分を超える工程または外部待ちがある場合、待機要否と次工程への影響を説明した

## B. 公式参照の確認

- [ ] ノクター公式設定マスターシートを実画像として参照できる
- [ ] NOCTER IDENTITY LOCK SHEETを実画像として参照できる
- [ ] 記憶や文章説明だけでノクターを再現しようとしていない
- [ ] 不採用画像・試作画像をキャラクターデザインの基準にしていない

## C. 今回の変更範囲

制作前に、今回変更してよいものを明示する。

例：

- 表情
- ポーズ
- 背景
- 季節
- 小道具
- 構図

それ以外は変更しない。

- [ ] 今回変更してよい項目を特定した
- [ ] 今回変更してはいけない項目を特定した

## D. Identity Lock項目

以下は原則固定する。

- [ ] 顔・輪郭
- [ ] 目の形・サイズ・配置・琥珀色
- [ ] 巨大な尖った耳
- [ ] 小柄な頭身・体型
- [ ] 黒〜濃紺の毛色と基本毛並み
- [ ] 金色の発光模様の位置・量
- [ ] 尻尾の形・ボリューム・発光
- [ ] 黒紺系マント
- [ ] 星型ペンダント
- [ ] 左側の金タグ

## E. 生成指示の禁止事項

- [ ] ノクターを再デザインしない旨を入れた
- [ ] 原画にない線・模様・装飾を追加しない旨を入れた
- [ ] 毛や装飾を豪華化しない旨を入れた
- [ ] 写実化・高精細化を理由にデフォルメ感を変えない旨を入れた
- [ ] 変更許可領域以外を維持する旨を入れた

固定補助文：

`If a marking, line, ornament, or accessory is not clearly present in the official reference, do not invent or add it.`

## F. 参照画像の絞り込み

通常の正面系制作では原則として、

1. 公式設定マスターシート
2. Identity Lock Sheet
3. 今回必要な補助資料1点

を中心にする。

- [ ] 無関係な参照画像を大量に与えていない
- [ ] 横向き・背面等の場合だけ必要な角度資料を追加している
- [ ] 細部資料は、その部位が崩れる場合にのみ追加している

## G. 二段階制作

可能な場合は、

**Identity Lock → Scene Edit**

の順で進める。

- [ ] まずキャラクター単体で同一性を確認できる
- [ ] 背景・演出を一発生成に混ぜず、後工程へ分離できるか検討した

## H. 生成後採点

公式原画と比較して採点する。

| 項目 | 配点 |
| --- | ---: |
| 顔・輪郭 | 20 |
| 目 | 15 |
| 耳 | 15 |
| 頭身・体型 | 10 |
| 毛色・毛並み | 5 |
| 発光模様 | 10 |
| マント | 10 |
| ペンダント | 5 |
| 金タグ | 5 |
| 尻尾 | 5 |
| **合計** | **100** |

判定：

- **90点未満**：Scene Editへ進めない
- **90〜94点**：Scene Edit用の合格個体候補
- **95点以上**：基準個体候補。自動昇格はしない

## I. 修正ルール

- [ ] 修正は1回につき1〜2種類の問題に絞る
- [ ] 既に合っている部位を変更しない領域として扱う
- [ ] 修正後も再採点する
