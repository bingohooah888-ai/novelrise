# β版 露出配分ルール

**STATUS: SUPERSEDED**

**SUPERSEDED BY: `docs/exposure-allocation-beta-v2.md`**

> この文書は履歴調査用に保持している旧仕様です。Current State の露出配分仕様として使用しないでください。現行仕様は `docs/exposure-allocation-beta-v2.md` を参照してください。

## 目的

NOVELIGHTの露出は、課金でランキング順位や評価を買う仕組みにしない。Freeを含むすべての公開作品を発見対象に残しつつ、Standard/Premiumには「読者の前へ運ばれる機会」を追加する。

βでは固定インプレッション保証を行わず、直近の実績を見ながら相対的に露出が少ない作者・作品へ次の機会を回す。

## 配分単位

作品数だけで公平性を測らない。Premiumが30作品を投稿できること自体で、1作品のFree作者より30倍のホーム露出を獲得できる設計にはしない。

一般露出は次の順序を基本とする。

1. 同じ読者へ直近6時間に表示していない作品を優先する。
2. 1回の発見フィードでは、同一作者の2作品目より別作者の1作品目を先にする。
3. 直近7日間の作者単位インプレッションが少ない作者を優先する。
4. 同一作者内では、直近7日間の作品単位インプレッションが少ない作品を優先する。
5. 同程度なら読者ごとの安定したタイブレークで順序を分散する。

これにより「特定作品だけが露出を独占しない」と「作品数の多い作者だけがフィードを埋めない」を同時に守る。

## β版のプラン重み

初期値は以下とする。

- Free: 1.00
- Standard: 1.35
- Premium: 1.60
- Premium新作48時間: Premium重みにさらに1.20倍

これは永久仕様ではなく `beta-v1` の検証値である。Standardの露出改善が弱すぎる、Premiumが強すぎる、Freeのゼロ露出率が上がる等のデータが出た場合は調整する。

Premium専用露出枠はホームの一般枠を奪わない追加枠として扱う。一般枠にはFree/Standard/Premiumの全プランが参加し、その後に条件を満たすPremium作品がある場合だけ最大1件を追加する。

検索では「おすすめ」相当のデフォルト順にだけ露出重みを使う。ユーザーが明示的に新着順、PV順、お気に入り順を選んだ場合は、その選択を課金重みで上書きしない。

## インプレッション記録

配分候補を取得しただけではインプレッションに数えない。UIで実際に表示された作品を `record_novel_impressions` へ送って記録する。

同じ読者・同じ作品・同じ表示面は1時間に1回までとし、リロードだけでインプレッションが膨らみにくくする。

生の閲覧者キーを含む `novel_exposure_events` はクライアントから直接SELECT/INSERTできない。表示候補取得とインプレッション記録は専用RPC経由に限定する。

## βで見る指標

- Free作品のゼロインプレッション率
- プラン別の中央値インプレッション
- 作者単位の露出偏り
- 作品単位の露出偏り
- 同一読者への再表示率
- Standard/Premiumの追加露出量
- 追加露出から作品詳細へ進んだ割合

課金プランの価値は「順位」ではなく、追加された露出とその後の読書行動で評価する。
