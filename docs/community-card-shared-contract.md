# NOVELIGHT 交流投稿カード 共通管理契約

ホームの「みんなの交流」と `community.html` の投稿カードは **同一のカードコンポーネント** です。

- 描画処理：`novelight-community.js` の `card(row)` を両ページが使用します。日時・通報の配置、操作ボタンの有無を `isHome` で分岐しません。
- カードの唯一の見た目設定：`novelight-community-card.css`。両ページが最後に読み込みます。ネイビー背景、金色、文字サイズ、ボタン非表示、フォーム色はこのファイルだけで変更します。
- `novelight-community.css` はカードの基本構造と、ホーム3列 / 交流広場1列などの **ページ配置** を担当します。
- `novelight-community-ivory.css` は交流広場の背景・掲示板・通知の色を担当します。投稿カードのCSSをここに追加しないでください。
- カード本文はデスクトップ20px・スマホ19px、見出し22px、作者名19px、日時17pxで共通です。
- ♡件数、コメント件数、投稿共有の旧操作列は両ページで隠し、通報だけを日時の下に表示します。必要な既存データ/RPCとコメント深層リンクは残します。

更新時は `tests/community-visual-parity.test.mjs` と `tests/e2e/specs/community-plaza-ui.js` により同じ投稿の背景・色・文字サイズ・操作配置が両ページで一致することを検証します。片方だけの修正は禁止です。

ホーム3列に大きな文字が収まらない場合は、カード幅・行数・グリッドのレイアウトを調整し、文字サイズのページ間差を作らないでください。
