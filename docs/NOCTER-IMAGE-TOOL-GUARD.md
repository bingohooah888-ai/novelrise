# NOCTER IMAGE TOOL GUARD

**ChatGPT側画像生成ツールの誤発火防止ルール**

この文書は `docs/NOCTER-PREFLIGHT.md` の Q / R を補強する実行ガードである。ノクターのComfyUI/Krita等の編集経路構築中は、画像生成ツールの実行可否を必ず fail-closed で判定する。

## 1. デフォルト状態

- ComfyUI/Krita等の導入、設定、モデル配置、モデル認識、ノード構築、画像読み込み、マスク作成、スクリーンショット確認、操作案内中は **IMAGE_TOOL_LOCKED = true** とする。
- 状態が不明、文脈が曖昧、ユーザー意図の解釈に迷う場合も **LOCKEDのまま** とする。
- 画像添付が存在すること自体を、画像生成・画像編集の実行許可として扱わない。

## 2. 二重解除ゲート

ChatGPT側の画像生成ツールを呼ぶには、ユーザーの**最新メッセージ単体**が次の2条件を同時に満たす必要がある。

1. 完全一致フレーズ **`画像生成ロック解除`** を含む。
2. 同じ最新メッセージ内に、何を生成・編集するかという具体的な実行指示を含む。

片方でも欠けた場合は実行禁止とする。

例：

- `生成して` → 禁止
- `編集して` → 禁止
- `画像生成ロック解除` → 禁止（具体的指示不足）
- `画像生成ロック解除。この画像の右耳だけを編集して` → 実行可否の次段階確認へ進める

## 3. スクリーンショット強制禁止

最新メッセージの主目的が、ComfyUI/Krita等のUIスクリーンショットを見せて「できた」「これでいい？」「次は？」「どうする？」等の操作確認を求めることである場合、**画像生成ツール呼び出しを無条件で禁止**する。

この禁止は、スクリーンショット内に画像が表示されていても解除されない。

## 4. ツール呼び出し直前の二重チェック

画像生成ツールを呼ぶ直前に、内部的に次を順番に確認する。

- Check A: 最新メッセージに `画像生成ロック解除` があるか。
- Check B: 最新メッセージに具体的な生成・編集指示があるか。
- Check C: 最新メッセージの主目的がUI確認・操作案内ではないか。

AまたはBがNO、またはCがYESなら、画像生成ツールは呼ばずテキスト回答だけを返す。

## 5. 一回限りの解除

- 条件を満たして画像生成・画像編集を1回実行した後は、自動的に **IMAGE_TOOL_LOCKED = true** へ戻す。
- 継続解除は推定しない。
- 次の実行にも再度 `画像生成ロック解除` と具体的指示の両方を要求する。

## 6. 誤発火時の扱い

誤って画像生成ツールを呼んだ場合は、その出力をNOVELIGHTの正式ノクター素材、Identity Lock候補、基準個体、ベスト個体、次回編集元として扱わない。

同じ誤発火が再発した場合は、単に注意文を追加するだけでなく、実行判定をさらに厳しくする。原因確認が終わるまでChatGPT側画像生成ツールの利用を停止し、ComfyUI/Krita等の外部編集環境の操作案内だけを継続する。

## 7. 現在のセッション状態

現在のノクターComfyUI編集経路構築セッションでは、**IMAGE_TOOL_LOCKED = true** とする。

ユーザーが最新メッセージで `画像生成ロック解除` と具体的な生成・編集指示を同時に明示しない限り、ChatGPT側画像生成ツールを呼ばない。
