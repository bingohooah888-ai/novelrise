# NOVELIGHT β版 先行作者登録LP 画像制作仕様

この文書は、先行作者登録LPのHTML/CSSレイアウト骨格から逆算した、最終背景画像とノクター独立画像の制作仕様である。

## 1. 実装基準

- PC最大コンテンツ幅: `1180px`
- PCヘッダー: `78px`
- PC HERO: `660px` 固定
- Tablet / mobile主要breakpoint: `900px`
- Compact mobile breakpoint: `520px`
- 390px級スマホ HERO: `720px` 固定
- PC HERO本文ブロック: 最大 `640px`、HERO内部幅の `58%` まで
- PCノクター表示枠: `290 × 360px`
- 521〜900pxノクター表示枠: `210 × 260px`
- 520px以下ノクター表示枠: `200 × 248px`
- 背景画像はHEROのみ画像化候補とし、中段とFooterはCSSで構成する
- PC / mobile HERO背景は別素材に差し替え可能
- ノクターは背景と分離し、透過画像を独立配置する

## 2. 必要画像一覧

| 素材 | 必須 | 推奨制作サイズ | 比率 | 推奨形式 | 目標容量 |
| --- | --- | ---: | ---: | --- | ---: |

| Mobile HERO背景 | 必須 | 900 × 1600px | 9:16相当 | AVIF優先 / WebP | 180〜320KB以下 |
| ノクター透過 | 必須 | 800 × 1000px | 4:5 | 透過WebP優先 / PNG | 120〜280KB目安 |
| 中段背景 | 不要 | CSSで構成 | - | - | - |
| Footer背景 | 不要 | CSSで構成 | - | - | - |

既存の `assets/novelight-header-logo.webp` はそのままHTML側で使用し、新規制作対象には含めない。

## 3. A. PC HERO背景

| 項目 | 確定仕様 |
| --- | --- |
| 用途 | 先行作者登録LPのPC HERO背景美術。夜空、城、図書館、本棚、ランタン、本、暖色光などの世界観のみを含める |
| CSS実表示 | viewport幅 × `660px`。代表確認幅は `1280 / 1440 / 1920px` |
| 推奨制作pixel | `2560 × 1280px` |
| 推奨アスペクト比 | `2:1` |
| background-size | `cover` |
| background-position | `center 46%` |
| 重要被写体の総合安全領域 | 元画像の `x=4〜96% / y=16〜84%`。この外側へ置く要素はcrop可能な装飾に限定 |
| 文字を避ける範囲 | `x=6〜58% / y=18〜82%`。ここは低コントラスト・低密度の背景にする |
| ノクターを避ける範囲 | `x=68〜94% / y=38〜97%`。重要建築・ランタン・本の主役を置かない |
| 城の推奨範囲 | 主役部分を `x=58〜82% / y=8〜52%`。特に尖塔等の重要部分は `x=60〜74% / y=16〜42%` を推奨 |
| 本棚の推奨範囲 | 左 `x=0〜12% / y=20〜100%`、右 `x=88〜100% / y=20〜100%`。端はcrop前提の補助要素とする |
| ランタンの推奨範囲 | 右上 `x=84〜94% / y=10〜34%` または左上 `x=2〜10% / y=12〜32%`。中央には置かない |
| 本・暖色光 | 下辺・側辺へ分散可能。ただし `x=6〜58% / y=18〜82%` では文字可読性を優先し強いハイライトを避ける |
| 人物／ノクター | 背景へ焼き込まない。人物を追加しない。ノクターは独立レイヤーのみ |
| 文字・ロゴ・CTA | 背景へ焼き込まない |
| 推奨形式 | AVIF。制作・互換性都合ではWebP |
| 目標容量 | AVIF/WebPで `350〜550KB以下` を目安。品質を落とさず可能なら400KB前後 |

### PC cover cropの目安

`2560 × 1280` を `cover` で表示した場合の代表的なcropは以下。

- `1280 × 660`: 左右それぞれ元画像約 `39px`（約1.5%）がcrop
- `1440 × 660`: 上下それぞれ元画像約 `53px`（約4.2%）がcrop
- `1920 × 660`: 上下それぞれ元画像約 `200px`（約15.6%）がcrop

したがって、城の尖塔・ランタンなど切れて困る要素を元画像の上下 `16%` より外へ置かない。左右端の本棚や光はcropされても成立する装飾として制作する。

## 4. B. Mobile HERO背景

| 項目 | 確定仕様 |
| --- | --- |
| 用途 | 900px以下、特に390px級スマホ向けHERO背景美術 |
| CSS実表示 | 代表 `390 × 720px`。HEROは `720px` 固定 |
| 推奨制作pixel | `900 × 1600px` |
| 推奨アスペクト比 | `9:16相当`（0.5625） |
| background-size | `cover` |
| background-position | `center 48%` |
| 重要被写体の総合安全領域 | `x=4〜96% / y=4〜96%` |
| 文字を避ける範囲 | `x=8〜92% / y=5〜58%`。タイトル、コピー、公開時期、CTAの背面を静かにする |
| ノクターを避ける範囲 | `x=23〜77% / y=62〜98%` |
| 城の推奨範囲 | 左下寄り `x=2〜26% / y=50〜78%`。重要尖塔は `x=5〜22% / y=50〜64%` |
| 本棚の推奨範囲 | 左 `x=0〜14% / y=20〜100%`、右 `x=86〜100% / y=20〜100%`。端部はcrop許容 |
| ランタンの推奨範囲 | 右上 `x=80〜94% / y=10〜30%`。強い光源はタイトル中央へ侵入させない |
| 本・暖色光 | HERO下部・左右へ配置可。中央下はノクター用に空ける |
| 人物／ノクター | 背景へ焼き込まない |
| 文字・ロゴ・CTA | 背景へ焼き込まない |
| 推奨形式 | AVIF。制作・互換性都合ではWebP |
| 目標容量 | `180〜320KB以下`、可能なら250KB前後 |

### Mobile cover cropの目安

`900 × 1600` を `390 × 720` に `cover` すると、左右それぞれ元画像約 `17px`（約1.9%）のみがcropされる。390px表示では9:16が非常に近いため、PC素材を流用するよりMobile専用素材を制作した方が構図を安定させやすい。

## 5. C. 中段背景

**新規画像は不要。**

「先行登録で受け取れること」は羊皮紙調CSS、「NOVELIGHTとは？＋フォーム」は濃紺のCSSグラデーション＋羊皮紙カードで構成する。画像を追加しないことで、HERO以降の表示速度と文字可読性を優先する。

## 6. D. Footer背景

**新規画像は不要。**

Footerは `#07111e` 系の単色CSSを使用する。世界観用画像を追加する効果より、ページ末尾の軽量性と法務リンクの可読性を優先する。

## 7. E. ノクター独立画像

| 項目 | 確定仕様 |
| --- | --- |
| 推奨制作サイズ | `800 × 1000px` |
| 推奨比率 | `4:5` |
| PC実表示 | `290 × 360px` |
| PC位置 | `1180px` HERO innerの右端から `2%`（約24px）、HERO下端から `30px` |
| 521〜900px実表示 | `210 × 260px`、水平中央、下端 `20px` |
| 390px級実表示 | `200 × 248px`、水平中央、下端 `18px` |
| 推奨pixel密度 | PC実表示に対して約 `2.75x`、390px級に対して約 `4x`。800×1000で高DPIに十分 |
| 推奨形式 | 透過WebP優先。品質・制作工程上必要なら透過PNG |
| 透明余白 | 左右それぞれ `6%`（48px）、上下それぞれ `6%`（60px）を基準。耳・尻尾・発光・影が端で切れないこと |
| 背景への焼き込み | 禁止。必ず独立透過画像 |
| 目標容量 | WebPで `120〜280KB` 程度を目安 |

ノクターはNOVELIGHTより主役にしない。PCではタイトル・CTAの右側に独立して存在し、スマホではコピーとCTAの下へ移動する。文章・CTAを覆わないことを優先する。

## 8. HTML/CSSへの最終組み込み方法

現在の骨格では以下のCSS custom propertyを差し替えるだけで背景を切り替えられる。

```css
:root {
  --beta-hero-bg-desktop: url("assets/beta-authors-hero-desktop.avif");
  --beta-hero-bg-mobile: url("assets/beta-authors-hero-mobile.avif");
  --beta-noctar-image: url("assets/beta-authors-noctar.webp");
}
```

最終ノクター素材を組み込むときは、`beta-authors.html` の `.noctar-layer` から `is-placeholder` classだけを外す。

背景画像内には、文字、NOVELIGHTロゴ、CTA、フォーム、Founding Authors文字、ナビゲーション、ノクターを含めない。

## 10. セクション高さ・余白

- HERO: PC `660px` / 900px以下 `720px`
- 先行登録で受け取れること: PC `min-height:350px`, padding top `70px`, bottom `76px`; mobileはcontent-driven, top `58px`, bottom `64px`
- NOVELIGHTとは？＋フォーム: content-driven。PC top `88px`, bottom `96px`; 900px以下 top `64px`, bottom `70px`
- About card: PC `min-height:560px`
- Form card: PC `min-height:720px`
- Founding Authors: PC `min-height:370px`, top `74px`, bottom `80px`; mobile content-driven, top `62px`, bottom `68px`
- Footer: PC `min-height:92px`; compact mobile `min-height:108px`

固定高さを多用せず、HERO以外は本文量・validation message・success/error stateで自然に伸長できる構造を維持する。

## 11. 制作時の禁止事項

- ページ全体を1枚の巨大画像にしない
- PC背景を単純cropしてMobile背景に流用しない
- 文字、ロゴ、CTA、フォームを画像へ焼き込まない
- ノクターを背景へ焼き込まない
- Founding Authorsの文字やバッジ説明を画像化しない
- 重要被写体をcrop許容域へ置かない
- 2560×1280 / 900×1600を大幅に超える過剰解像度を、用途なく採用しない

この仕様は最終背景制作担当がそのまま座標基準として利用できることを目的とする。
