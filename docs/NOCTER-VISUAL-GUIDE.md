# NOCTER VISUAL GUIDE

**NOVELIGHT公式マスコット「ノクター」制作・再現ルール**

**制定：2026年8月25日**

本書は `docs/NOVELIGHT-MASTER.md` 第11章「ノクター」の公式デザイン原則を、実制作で再現性高く運用するための詳細ガイドである。

## 1. 最上位原則

ノクターを描く際は、指定された公式基準原画を最上位の視覚基準とする。

「新しいノクターを生成する」のではなく、「同じノクターを別の場面で描く」。

AIによる「改善」「アレンジ」「映えるようにする」等を理由としてキャラクターデザインを変更しない。

文章設定と公式原画が矛盾した場合は、公式原画を優先する。

絵としての華やかさより、同一キャラクターとしての一貫性を優先する。

## 2. 原則変更禁止の要素

以下は、明示的なデザイン改訂を行わない限り変更しない。

- 顔の輪郭・基本的な顔立ち
- 目の形、基本サイズ、配置、琥珀色
- 巨大で尖った耳の形・シルエット
- 小柄なデフォルメ体型・基本頭身
- 黒〜濃紺の毛色
- 基本的な毛並み・毛のシルエット
- 金色の発光模様の基本デザイン
- 大きなふさふさした尻尾
- 尻尾の発光表現・基本形状
- 黒紺系マントの基本デザイン
- ペンダント、タグ等の主要装飾
- ノクター全体の黒紺＋金という基本配色

特に、かわいく見せるために目を過度に巨大化する、顔を丸く幼くする、毛を過剰に豪華にする、発光模様を勝手に増やす、装飾を別デザインへ置き換えることを禁止する。

## 3. 変更可能な要素

以下は用途に応じて変更可能とする。

- ポーズ
- 表情
- 視線
- 背景
- 時間帯
- 季節
- 構図
- 小道具
- 光・エフェクトの演出

ただし、これらの変更を理由として第2章の固定要素を再解釈・改変しない。

## 4. 画像制作方式の優先順位

可能な場合は、ゼロからの新規生成よりも公式画像を基にした編集を優先する。

優先順位：

1. 公式画像を直接編集して用途に合わせる
2. 公式画像を最上位参照として新規生成する
3. 正式採用済み画像を補助参照として利用する

前回生成した画像だけを次回の基準にすることは禁止する。世代を重ねるほどデザインが変形する「伝言ゲーム」を防ぐ。

## 5. 参照画像の優先順位

制作時の参照優先順位は以下とする。

1. 公式マスター原画
2. 顔・耳・目・マント・尻尾・装飾等の部位別公式資料
3. 過去に正式採用されたノクター画像
4. 今回の編集対象画像

不採用画像、試作画像、原画からズレた生成画像はキャラクターデザインの基準にしない。

正式採用された画像であっても、自動的に新しい公式基準へ昇格させない。

「この画像を公式基準にする」と明示的に決定された画像のみ基準資料へ追加する。

## 6. 制作時の参照順序

毎回、原則として以下の順序で参照する。

**公式マスター原画**
→ **必要な部位別公式資料**
→ **今回の用途に近い正式採用画像**
→ **今回の具体的な制作指示**

この順序を崩して、直近の生成画像を最優先しない。

## 7. 生成・編集後の確認項目

完成画像は公開・採用前に、公式原画と比較して以下を確認する。

- 顔の輪郭は変わっていないか
- 目の形・サイズ・配置・色は近いか
- 耳の形・大きさ・角度が大きく崩れていないか
- 頭身・体型が変わっていないか
- 毛色・毛並みが別キャラクター化していないか
- 発光模様を勝手に変更・追加していないか
- 尻尾の形・ボリューム・発光が維持されているか
- マントの基本デザインが維持されているか
- ペンダント等の主要装飾が別物になっていないか
- 全体として「似たキャラクター」ではなく「同じノクター」に見えるか

絵として美しくても、上記に大きなズレがある場合は公式素材として採用しない。

## 8. 採用判断の優先順位

ノクターの公式素材では、

**ブランド一貫性 ＞ 画力・豪華さ・演出の派手さ**

とする。

100点の美麗な別キャラクターより、85点でも同じノクターに見える画像を採用する。

## 9. 公式マスター画像の考え方

今後、すべてのノクター画像の親となる「公式ノクターマスター画像」を1枚設定する。

望ましい条件：

- 正面
- 通常表情
- 全身が確認できる
- 顔、耳、目、体型、尻尾、マント、主要装飾、発光模様が確認できる
- 背景・演出が控えめで、キャラクター本体を判別しやすい

公式マスター画像はX投稿向けの華やかなイラストとは役割を分ける。

X・広告用画像は公式マスター画像を基準として制作する。

## 10. 部位別公式資料

必要に応じて以下を個別資料として整備する。

- 顔正面
- 横顔
- 目
- 耳
- 発光模様
- マント
- ペンダント・タグ
- 尻尾

細部の再現性が不足する場合、文章指示を増やすだけでなく、該当部位の公式画像資料を参照する。

## 11. 画像生成AIの限界を前提とする

生成AIは参照画像を完全コピーして別ポーズへ変形する仕組みではなく、参照情報を基に再生成するため、一定のブレが発生し得る。

したがって、プロンプトだけで完全固定できると考えず、

公式資料の整備
→ 編集方式の優先
→ 生成後比較
→ 不採用画像を基準化しない

という運用によってブレを抑える。

## 12. 長期的な高度固定

ノクターをX、広告、サイト、動画、グッズ等へ大量展開し、通常の参照画像方式では一貫性が不足する段階になった場合、キャラクター専用学習モデル、LoRA、ポーズ制御等の導入を検討する。

ただし、新しい技術を使うこと自体を目的にせず、品質、一貫性、制作速度、運用コストを比較して採用する。
