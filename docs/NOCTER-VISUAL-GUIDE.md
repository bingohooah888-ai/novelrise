# NOCTER VISUAL GUIDE

**NOVELIGHT公式マスコット「ノクター」制作・再現ルール**

**制定：2026年8月25日**  
**更新：2026年8月25日**

本書は `docs/NOVELIGHT-MASTER.md` 第11章「ノクター」の公式デザイン原則を、実制作で再現性高く運用するための詳細ガイドである。

## 1. 最上位原則

ノクターを描く際は、指定された公式基準原画を最上位の視覚基準とする。

「新しいノクターを生成する」のではなく、「同じノクターを別の場面で描く」。

AIによる「改善」「アレンジ」「映えるようにする」等を理由としてキャラクターデザインを変更しない。

文章設定と公式原画が矛盾した場合は、公式原画を優先する。

絵としての華やかさより、同一キャラクターとしての一貫性を優先する。

公式原画を実画像として参照できない状態では、原則として公式素材用のノクター画像を生成しない。記憶や文章説明だけで再現しようとしない。

## 2. 公式視覚基準

最上位基準は、2026年8月20日に確定したノクターの三面図・ディテール・表情・カラーパレット・NG例を含む公式設定シートとする。

正式名称：**ノクター公式設定マスターシート**

このマスターシートは、人間向けの設定正本であり、顔、耳、目、体型、毛色、発光模様、尻尾、マント、ペンダント、金タグその他主要要素の最終判断基準とする。

生成AIへ与える情報量を整理するため、マスターシートから描き直しを行わずに切り出し・合成した **NOCTER IDENTITY LOCK SHEET** を生成専用の補助基準として使用する。

Identity Lock Sheetは公式原画を上書きする新デザインではない。常に公式マスターシートの下位に置く。

## 3. 原則変更禁止の要素

以下は、明示的なデザイン改訂を行わない限り変更しない。

- 顔の輪郭・基本的な顔立ち
- 目の形、基本サイズ、配置、琥珀色
- 巨大で尖った耳の形・シルエット
- 小柄なデフォルメ体型・基本頭身
- 黒〜濃紺の毛色
- 基本的な毛並み・毛のシルエット
- 金色の発光模様の基本デザイン・位置・量
- 大きなふさふさした尻尾
- 尻尾の発光表現・基本形状
- 黒紺系マントの基本デザイン
- 星型ペンダント
- 左側の金タグ
- ノクター全体の黒紺＋金という基本配色

特に、かわいく見せるために目を過度に巨大化する、顔を丸く幼くする、毛を過剰に豪華にする、発光模様を勝手に増やす、装飾を別デザインへ置き換えることを禁止する。

**公式原画に明確に存在しない線・模様・装飾は追加しない。**

「空いているから足す」「映えるから増やす」「高級感を出すために装飾する」といった生成AI側の補完を禁止する。

## 4. 変更可能な要素

以下は用途に応じて変更可能とする。

- ポーズ
- 表情
- 視線
- 背景
- 時間帯
- 季節
- 構図
- 小道具
- 光・エフェクトの演出

ただし、これらの変更を理由として第3章の固定要素を再解釈・改変しない。

## 5. 画像制作方式の優先順位

可能な場合は、ゼロからの新規生成よりも公式画像または合格済み基準個体を基にした編集を優先する。

優先順位：

1. 公式原画・基準個体を直接編集して用途に合わせる
2. 公式マスターシート＋Identity Lock Sheetを最上位参照として新規生成する
3. 正式採用済み画像を補助参照として利用する

前回生成した画像だけを次回の基準にすることは禁止する。世代を重ねるほどデザインが変形する「伝言ゲーム」を防ぐ。

## 6. 参照画像の与え方

参照画像は多ければよいとは限らない。矛盾するポーズや情報を大量に与えると、生成側の再解釈が増える可能性がある。

通常の正面系制作では、原則として以下の3点を中心にする。

1. ノクター公式設定マスターシート
2. NOCTER IDENTITY LOCK SHEET
3. 今回必要な正面全身または顔アップ等の補助資料1点

横向き、背面、特定装飾の厳密再現等では、その用途に必要な資料だけを追加する。

目・耳・ペンダント・金タグ・尻尾・マント等の細部資料は、該当部位が崩れる場合に追加し、無関係な資料を常時すべて与えない。

## 7. 制作を二段階に分ける

ノクターと背景・演出を一発で完成させることを原則としない。

### 第1段階：Identity Lock

まず、無地または極めて単純な背景で、ノクター本体の同一性だけを確認する。

基本条件：

- ノクター単体
- 正面または必要最小限の角度
- 通常表情
- 背景演出を抑える
- 不要な小道具を入れない

ここで顔、目、耳、体型、模様、マント、装飾、尻尾が基準を満たすまで調整する。

### 第2段階：Scene Edit

Identity Lockを通過した個体を土台として、背景、季節、表情、小道具、ポーズ等を必要最小限編集する。

シーン編集後も再び公式原画と比較し、キャラクター本体が変形していないか確認する。

## 8. 修正は局所的・段階的に行う

複数の崩れを一度に修正すると、直した箇所と引き換えに別の箇所が変形する可能性がある。

原則として1回の修正では1〜2種類の問題に絞る。

推奨順：

1. 顔輪郭・目
2. 耳
3. ペンダント・金タグ
4. マント
5. 発光模様
6. 尻尾
7. その他

既に合っている部位は「変更しない領域」として明示する。

## 9. 生成時の固定禁止文

公式素材制作では、意味として以下を毎回含める。

- ノクターを再デザインしない
- 公式原画と同じキャラクターとして扱う
- 公式原画にない模様・線・装飾を追加しない
- 顔、目、耳、体型、発光模様、マント、ペンダント、金タグ、尻尾を再解釈しない
- 毛や装飾を豪華化しない
- 写実化・高精細化を理由に原画のデフォルメ感を変えない
- 変更を許可された部分以外は維持する

英語指示を併用する場合も、少なくとも以下の考え方を含める。

`If a marking, line, ornament, or accessory is not clearly present in the official reference, do not invent or add it.`

## 10. 生成・編集後の採点

公開・採用前に、公式原画と比較して100点満点で確認する。

| 項目 | 配点 |
| --- | ---: |
| 顔・輪郭 | 20 |
| 目 | 15 |
| 耳 | 15 |
| 頭身・体型 | 10 |
| 毛色・毛並み | 5 |
| 発光模様 | 10 |
| マント | 10 |
| ペンダント | 5 |
| 金タグ | 5 |
| 尻尾 | 5 |
| **合計** | **100** |

目安：

- **90点未満**：公式シーン制作へ進めない
- **90〜94点**：シーン展開用の合格個体候補
- **95点以上**：基準個体候補。ただし自動的に公式基準へ昇格させない

採点は絶対的な画像認識精度を意味するものではない。感覚だけで採用することを避け、毎回同じ観点で比較するための運用基準とする。

## 11. 採用判断の優先順位

ノクターの公式素材では、

**ブランド一貫性 ＞ 画力・豪華さ・演出の派手さ**

とする。

100点の美麗な別キャラクターより、85点でも同じノクターに見える画像を優先する。

ただし、Identity Lock工程では90点未満をシーン制作へ進めない。

## 12. 正式採用画像の扱い

X投稿、広告、サイト等に実際に使用した画像であっても、自動的に新しい公式基準へ昇格させない。

正式採用画像は、公式マスターシートとIdentity Lock Sheetより下位の補助参照とする。

「この画像を公式基準にする」と明示的に決定された場合のみ、基準資料への追加を検討する。

不採用画像、試作画像、原画からズレた生成画像はキャラクターデザインの基準にしない。

## 13. Preflightを必須化する

ノクターの画像生成・編集を開始する前に `docs/NOCTER-PREFLIGHT.md` を確認する。

Preflightを通過していない状態では、公式素材用の画像生成を開始しない。

少なくとも以下を確認する。

- 公式マスターシートを実画像として参照できる
- Identity Lock Sheetを参照できる
- 今回変更してよい項目が明確
- 今回変更してはいけない項目が明確
- 使用する参照画像を必要最小限に絞った
- 原画にない装飾を追加しない指示が入っている
- キャラクター固定と背景演出を分離できる場合は分離する
- 作業開始前の所要時間提示が完了している

## 14. 画像生成AIの限界を前提とする

生成AIは参照画像を完全コピーして別ポーズへ変形する仕組みではなく、参照情報を基に再生成するため、一定のブレが発生し得る。

したがって、プロンプトだけで完全固定できると考えず、

公式資料の整備
→ Identity Lock
→ 局所修正
→ 採点
→ Scene Edit
→ 再採点

という運用によってブレを抑える。

## 15. 専用学習モデルへの移行条件

通常の参照画像＋編集方式で複数回改善しても、95点前後の一貫性を安定して維持できない場合、またはX、広告、サイト、動画、グッズ等へ大量展開する段階で制作コストが高くなった場合、キャラクター専用学習モデル、LoRA、ポーズ制御等を検討する。

専用学習へ進む前に、学習データには原画からズレた試作画像を混ぜない。

学習候補は、公式マスターシート、公式部位資料、95点以上と判断された正式基準候補等に限定する。

新しい技術を使うこと自体を目的にせず、品質、一貫性、制作速度、運用コストを比較して採用する。

## 16. Identity Lock 改善ルール（2026-08-25追加）

以下は、実テストで確認した生成ブレを踏まえた最新のIdentity Lock運用であり、Identity Lockテスト時は第6〜8章の一般則より優先する。

### 16.1 顔基準は高精細原画から取る

顔の基準資料は、小さな三面図の正面全身を拡大したものを原則として使わない。

公式マスターシート内に、より大きく高精細に描かれた公式ノクターがある場合、その大型原画から顔を直接切り出す。

三面図の正面全身は頭身・全身シルエット確認に使い、大型原画の顔アップは顔輪郭・目・鼻口・頬毛等の確認に使う。役割を混同しない。

### 16.2 正面Identity Lockテストは原則4点参照

正面・通常表情のIdentity Lockテストでは、参照を原則として以下の4点に絞る。

1. ノクター公式設定マスターシート
2. 三面図から切り出した正面全身
3. 大型公式原画から切り出した高精細な顔アップ
4. 公式ディテールから作った目＋耳の参照

NOCTER IDENTITY LOCK SHEETは引き続き補助基準として保持するが、上記4点と情報が重複して生成側の解釈を増やす場合は、正面テストへ機械的に追加しない。

装飾資料は頭部固定が完了する前に大量投入しない。

### 16.3 Identity Lockは三段階で固定する

Identity Lockを一度に全身完成させない。

**第1段階：頭部固定**

- 顔の横幅・輪郭
- 頬の毛量と形
- 鼻から口までの距離
- 目の丸さ・大きさ・間隔・琥珀色
- 耳の幅・高さ・角度
- 頭頂部の毛・カール

この段階では首から下の完成度を主評価にしない。

**第2段階：シルエット固定**

- 頭身
- 胴体幅
- 前脚・後脚
- 耳を含む全体シルエット
- 尻尾の形・ボリューム

**第3段階：装飾固定**

- マント
- 星型ペンダント
- 左側の金タグ
- 発光模様

第1段階が不合格のまま、第2・第3段階の細部を詰めない。

### 16.4 Identity Lock中は発光・演出を抑える

Identity Lock中は、公式模様の判別に必要な最低限の発光のみ許可する。

背景光、魔法粒子、火花、過度なブルーム、高輝度の金色演出等を原則入れない。

強い発光を理由として、頬・額・脚・マント等へ原画にない金模様を生成させない。

発光演出はIdentity Lock合格後のScene Editで戻す。

### 16.5 修正は「差分」だけを対象にする

修正指示は「もっと原画に似せる」のような全体再解釈ではなく、公式原画との差分を具体的に列挙する。

例：

- 原画より目が縦長
- 原画より頬が狭い
- 原画より鼻と口の距離が短い
- 額に原画にはない金模様がある

既に一致している領域は保持し、差分がある1〜2項目だけを局所修正する。

局所修正で済む場合、キャラクター全体をゼロから再生成しない。

### 16.6 生成AIと評価工程を分離する

画像生成AIへ依頼する仕事は、原則として**ノクター本体の生成・編集だけ**とする。

生成AIに、比較表、採点表、QAシート、説明文、合否判定等を同じ画像内へ作らせない。

公式原画との比較、差分抽出、100点採点、合否判断は生成後の別工程として行う。

画像内にAI自身が出した点数や評価文があっても、それを正式な評価として採用しない。

### 16.7 Scene Editへ進む条件

頭部固定 → シルエット固定 → 装飾固定の順に確認し、最終採点が90点以上になってからScene Editへ進む。

95点以上は基準個体候補とするが、ユーザーの明示的な決定なしに公式基準へ昇格させない。
